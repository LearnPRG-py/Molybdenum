# Contribution guide

## Github PR system

This project uses github's built-in PR system for code updates and issue fixes.

## Making A PR

To make a PR, one must first fork the repository and make edits on their local copy.

After this they can commit and push to their fork, and click on the contribute option to open a Pull Request.

A PR must be attached to an issue, for issue-specific discussions if any. If an issue is not present, one should be created.

## Before Clicking This Option

Before you PR, double check your code for style compliance and check if it runs (although it can be done after making the PR as well).

## The PR Process

After the code has been PRed, the tests would be run by github actions to verify no new regressions were created. After this, code changes

have to be approved by any 2 users with commit access (or fewer if there are fewer users with commit access). Uploads or LGTMs count as "approvals".
